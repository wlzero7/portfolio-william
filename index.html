FinControl ⭐

Meu maior projeto até o momento. Sistema financeiro web completo desenvolvido em PHP, MySQL, HTML, CSS e JavaScript. O sistema permite cadastro e login de usuários, gerenciamento de receitas e despesas, categorias financeiras, metas, relatórios, exportação de dados em PDF e CSV e personalização de perfil com foto.

O projeto foi desenvolvido localmente com XAMPP e publicado na internet com banco de dados MySQL hospedado na InfinityFree.
